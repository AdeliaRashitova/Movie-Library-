## Описание программы

«Movie Library» — это графическое приложение для учёта и систематизации коллекции фильмов. Программа позволяет:
* добавлять фильмы с указанием названия, жанра, года выпуска и рейтинга;
* просматривать все добавленные фильмы в виде таблицы;
* фильтровать фильмы по жанру и году выпуска;
* сохранять коллекцию в JSON‑файл и загружать её при следующем запуске;
* генерировать случайные рекомендации фильмов (из локальной коллекции или через TMDB API);
* проверять корректность вводимых данных.

Программа решает задачу удобного хранения информации о фильмах и быстрого поиска нужных картин по ключевым параметрам.

## Технологический стек

* **GUI:** Tkinter (встроенная библиотека Python);
* **хранение данных:** JSON;
* **работа с API:** TMDB API (The Movie Database) для получения случайных рекомендаций;
* **генерация случайных данных:** библиотека `random`;
* **тестирование:** модуль `unittest`;
* **контроль версий:** Git;
* **документация:** Markdown (README.md).

## Функциональность

1. **Форма добавления фильма:**
   * поле «Название» (обязательное);
   * поле «Жанр» (обязательное);
   * поле «Год выпуска» (число от 1888 до текущего года);
   * поле «Рейтинг» (число от 0 до 10 с одним знаком после запятой);
   * кнопка «Добавить фильм».

2. **Таблица фильмов:** отображает все добавленные фильмы с колонками: название, жанр, год выпуска, рейтинг.

3. **Фильтрация:**
   * выпадающий список жанров;
   * поле для ввода года выпуска;
   * кнопки «Применить фильтр» и «Сбросить фильтры».

4. **Кнопки управления:**
   * «Сохранить в JSON» — сохраняет коллекцию в файл `movies.json`;
   * «Загрузить из JSON» — загружает коллекцию из файла `movies.json`;
   * «Случайная рекомендация» — запрашивает случайный фильм через TMDB API или выбирает из локальной коллекции.

5. **Валидация ввода:** проверка всех полей на корректность данных с выводом понятных сообщений об ошибках.

6. **Тестирование:** набор тестов для проверки основных функций приложения.

## Инструкция по запуску

### Предварительные требования

* Python 3.8 или выше;
* библиотека `requests` для работы с API (`pip install requests`).

### Шаги по запуску

1. Клонируйте репозиторий:
   ```bash
   git clone <ссылка_на_репозиторий>
2. Перейдите в папку проекта:
   ```bash
   cd movie_library
3. Установите зависимости:
   ```bash
   pip install requests
4. Запустите приложение:
   ```bash
      python main.py
