## Описание программы

Movie Library — графическое приложение для учёта личной коллекции фильмов. Программа позволяет:
* добавлять фильмы с указанием названия, жанра, года выпуска и рейтинга;
* просматривать коллекцию в виде удобной таблицы;
* фильтровать фильмы по жанру и году выпуска;
* сохранять данные в формате JSON между запусками приложения;
* загружать сохранённые данные при старте программы;
* проверять корректность вводимых данных.

Приложение полезно для киноманов, коллекционеров фильмов и всех, кто хочет систематизировать свою фильмотеку.

---

## Требования для запуска

Для работы приложения необходимо:
* Python 3.8 или выше;
* установленные библиотеки: `tkinter` (встроена в Python), `json`.

## Используемые технологии

- **Python 3** — язык программирования
- **Tkinter** — стандартная GUI-библиотека Python
- **JSON** — формат хранения данных
- **Git** — система контроля версий
